# India Market Dashboard

Static portal (GitHub Pages) showing India index valuation, index returns, sector returns and FII/DII flows from NSE data.

- Data file: `data/dashboard.json`, written by `Scripts/refresh_india_dashboard.py --push` from the EA Demo workspace.
- Presentation: `index.html`, `style.css`, `app.js`. Data and presentation are separate, so redesigns do not touch data.
- Installable as a PWA. For information only, not investment advice.
